# Bangla-Cal draft dataset card

**AWAITING HUMAN REVIEW — not a frozen benchmark release.**

## Contents and intended use

The initial batch has 60 original AI-drafted candidate questions, ten in each
of the six categories specified in the [research spec](../bengali-ai-reliability-benchmark-spec.md).
Six separate examples demonstrate the schema; five example IDs are reserved for
pilot work. The planned first reviewed release remains 400–600 questions,
roughly evenly distributed. No final size/category split has been changed.

Use this draft to review the construction protocol and exercise the software.
Do not use its preliminary scores for model rankings, deployment decisions, or
claims about Bengali speakers. No native-speaker or factual verification has
been completed. All actual question records retain `reviewed_by: []`.

## Creation and provenance

AI drafted Bengali questions, English glosses, candidate answers/behaviors, and
source notes under the maintainer's specification. Source notes are verification
leads, not evidence that the cited material was checked by a human. No human
authorship, reviewer recruitment, or sign-off is inferred. The Git history
records draft changes. Question IDs retain the specification's `ban-cal-` prefix.

The batch includes stable facts, Bangladesh-specific facts, temporal uncertainty,
ambiguity, unanswerable/adversarial premises, and Bengali-English code switching.
English glosses and reference answers must never enter evaluated-model prompts.
Null temporal ground truths remain ineligible for factual calibration until
dated reference evidence is captured. Behavior can be graded separately.

## Review and coverage limitations

The local-knowledge batch currently emphasizes heritage topics. It does not yet
represent banking, public services, or educational deployments broadly. Standard
formal Bengali and deliberate code switching are the intended scope; dialects,
informal registers, and regional balance have not been validated. AI drafts may
contain unnatural language, factual errors, misleading premises, and repetition.

Two independent native Bengali speakers must review each item under
[CONSTRUCTION.md](CONSTRUCTION.md), resolve disagreements, and re-review changed
content. The maintainer verifies reviewer identity/independence and retains the
first decisions. Blank [review forms](review-forms/batch01/) bind each decision
to a question-content hash. Tooling checks evidence consistency; it cannot prove
that a named person actually conducted a review. No software action grants review.

After human-guided expansion and review, freeze a version with its source
archives and a SHA-256 manifest before the full evaluation. Keep the initial
pilot separate and disclose any prompt or rubric changes it motivated.
